# 武虾传奇 · Myth of Kungfu Shrimp

An original shrimp wuxia game in development: shape your martial artist through training and consequential choices, then put that build to the test in turn-based tactical battles.

The full game is under private development. A limited public demo will return after its content boundary and controls have been verified. Cooperative play is a development goal, not a currently released feature.

Earlier prototype source and builds were publicly distributed. This page does not claim to withdraw those historical releases. Future updates here contain selected development notes, not the complete development repository.

## Development update — 2026-09-05
We are fixing progress-loss and repeat-reward problems, tightening playtest isolation, and separating the public preview from the full game. The next milestone is a reliable playable slice where different training decisions visibly change combat.
